# Badminton shop website

A static e-commerce front end for a UK badminton specialist. Plain HTML, CSS and JavaScript, generated by a small Node script. It has no dependencies and no framework, so pages load fast and can be hosted anywhere (Netlify, Vercel, Cloudflare Pages, S3).

```
npm run build    # writes the site to dist/
npm run serve    # preview at http://localhost:4321
npm run check    # build, then check for banned words, emoji, broken links, missing titles, gradients
```

Needs Node 18 or newer.

## Before launch: replace the placeholders

Anything in `[SQUARE BRACKETS]` is a fact the site needs from you. Most of them live in one file:

**`src/config.mjs`** holds the shop name, city, accent colour, phone, email, address, opening hours, company and VAT numbers, delivery prices, dispatch cut-off, returns window, restringing prices, payment methods and integration IDs. Enter numbers as numbers (`freeDeliveryThreshold: 50`). The basket then works out delivery and the "spend £X more" message.

To find the rest: `grep -rn "\[" src/pages.mjs src/data/content.mjs`

| What | Where |
| --- | --- |
| Products, prices, stock, specs | `src/data/products.mjs` (**sample data**: real model names, but prices and stock are made up) |
| Menus, category intros | `src/data/categories.mjs` |
| Buying guides, blog posts, FAQ | `src/data/content.mjs` |
| Policy pages, service pages | `src/pages.mjs` |

Have the terms, returns and privacy pages checked by a solicitor before launch.

## Photos

Every image is a grey box that says which photo goes there and the file name it expects. Put a file at that path under `src/static/img/` and rebuild. The placeholder is swapped for the photo automatically.

```
src/static/img/home/hero.jpg
src/static/img/categories/rackets.jpg
src/static/img/products/yonex-astrox-88d-pro-1.jpg   (main image)
src/static/img/products/yonex-astrox-88d-pro-2.jpg   (gallery, up to -5)
src/static/img/brands/yonex.png
src/static/img/blog/<post-slug>.jpg
src/static/img/store/front.jpg
```

`.webp`, `.jpg`, `.jpeg` and `.png` all work. Square product photos at 1200px work well. Compress them before uploading.

## Integrations (all off until you set them)

- **Reviews (Trustpilot):** set `trustpilotBusinessUnitId` in `config.mjs`. The reviews section on the home and store pages loads the TrustBox widget. Until then it shows an empty box. Do not add reviews by hand. To use a different TrustBox template, change `data-template-id` in `src/lib/html.mjs`.
- **Map:** set `mapQuery` to the real address. The Google Maps embed replaces the placeholder.
- **Forms** (contact, newsletter, restringing booking, teamwear, trade): set `formEndpoint` to a form handler (Formspree, Netlify Forms, or your own). Until then the forms say they are not connected.
- **Checkout:** the basket is stored in the browser. Set `checkoutUrl` once you have a payment provider, or move the catalogue to Shopify (Storefront API / Buy Button) or Stripe Checkout. The checkout button stays disabled until then.
- **Cookies:** the site sets no tracking cookies. If you add analytics, the Trustpilot widget or the map, update the privacy page and add a consent banner.

## Design rules

- Black, white and one accent colour (`accent` in config). The default is red `#C8102E`, which passes WCAG AA with white text.
- One typeface: Archivo (variable, self-hosted, SIL Open Font License). Headings use its condensed width.
- 2px corners, 1px borders, no gradients, no blur. `npm run check` fails if a gradient appears.

## Structure

```
build.mjs              builds dist/
serve.mjs              local preview server
scripts/check.mjs      pre-launch checks
src/config.mjs         shop facts
src/data/              products, categories/menus, guides/blog/FAQ
src/lib/html.mjs       layout, header, mega menu, footer, shared components
src/pages.mjs          every page
src/static/            CSS, JS, font, favicon, images (copied to dist/)
```

Pages: home, 6 category pages, new arrivals, best sellers, a page per product, Racket Finder, Services, Restringing, Teamwear, Trade Accounts, Visit Our Store, Buying Guides (4), Blog (3 posts), FAQ, Contact, Delivery, Returns, Terms, Privacy, Basket, Account, Search, 404. Also `sitemap.xml` and `robots.txt`.

Set `url` in `config.mjs` to the live domain so canonical tags and the sitemap are correct.
